## 👨‍💻 About Me

I'm a **Software & Full Stack Web Developer** focused on building practical applications that solve business problems, streamline workflows, and improve how information is managed.

My projects include a Learning Management System (LMS), an HR Information System (HRIS), and an Inventory and Sales Management System. I work primarily with JavaScript, Node.js, Express.js, and MySQL, while continuing to strengthen my skills in modern frontend development and software engineering.

I enjoy turning real-world requirements into functional, user-focused systems that are practical to use and maintain.

- ⚛️ **Frontend:** HTML5, CSS3, JavaScript, JSX, React, Tailwind CSS
- ⚙️ **Backend & Programming:** Node.js, Express.js, Python
- 🗄️ **Database:** MySQL, Relational Database Design
- 📊 **Development Tools:** Git, GitHub, VS Code, MySQL Workbench
- 🎨 **Design & Analytics:** Figma, Canva, Looker Studio
